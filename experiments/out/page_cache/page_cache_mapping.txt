Contract element  |  KV instance  ->  Page/Block-cache instance

Logical object    
    KV  : KV chunk (tenant, session, chunk)
    Page: logical page / block (file/dev, offset)
Incarnation g     
    KV  : generation stamped when chunk (re)enters the pool
    Page: reuse epoch stamped when the frame is (re)filled
Extent set S      
    KV  : one pool slot (single-extent KV)
    Page: one cache frame (page) or a run of frames (block)
Authoritative map 
    KV  : endpoint object directory: (id,g) -> slot
    Page: endpoint page table: (page,epoch) -> frame
Descriptor d      
    KV  : promotion <id,g,slot,len> from a host snapshot
    Page: async prefetch/read <page,epoch,frame,len>
Reuse event       
    KV  : evict chunk, bump gen, reuse slot for new chunk
    Page: evict page (LRU/ARC), bump epoch, refill frame
OAT (admission)   
    KV  : atomic: validate g == MAP[id].g, pin (id,g)
    Page: atomic: validate epoch == MAP[page].epoch, pin (page,epoch)
RPE               
    KV  : payload moves bytes of a reused chunk version
    Page: read/prefetch returns bytes of a reused frame's new page
Zero-RPE guarantee
    KV  : reject-before-payload; pin blocks reclaim in-flight
    Page: reject-before-read; pin blocks frame reuse in-flight
Payload path      
    KV  : endpoint DMA (Mode A) / host CXL.mem pull (Mode B)
    Page: endpoint DMA to page buffer / host CXL.mem page read
